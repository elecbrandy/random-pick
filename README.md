# Random Pick

선택한 알파벳 범위와 지정한 닫힌 숫자 범위에서 조합 하나를 뽑는 정적 웹사이트입니다.

## Local development

```bash
npm install
npm run dev
```

검사와 빌드는 다음 명령으로 실행합니다.

```bash
npm run typecheck
npm test -- --run
npm run build
```

## Range rules

- 알파벳 시작과 끝은 `A`부터 `Z`까지 선택하며 기본값은 `A`~`Z`입니다. 시작은 끝보다 뒤일 수 없습니다.
- 기본 범위는 `1`부터 `100`까지입니다.
- 최솟값과 최댓값은 안전한 정수여야 합니다. 앞뒤 공백, 부호(`+`, `-`), 앞의 `0`은 허용하며 `0`과 음수도 쓸 수 있습니다.
- 최솟값은 최댓값보다 작거나 같아야 하며, 포함된 정수의 개수도 안전한 정수 범위여야 합니다.

## Session history

- 확정된 `알파벳 · 숫자` 조합은 같은 탭의 세션에서 다시 뽑히지 않습니다. 범위를 바꿨다가 되돌려도 이미 뽑힌 조합은 제외됩니다.
- 기록은 최신순으로 표시되고 새로고침 뒤에도 복원됩니다. 범위 입력은 기본값으로 돌아가며 마지막 결과는 두 결과 칸에 다시 표시됩니다.
- 브라우저가 세션 저장소를 사용할 수 없으면 현재 열린 페이지의 기록은 유지하지만, 새로고침 뒤 사라질 수 있다는 안내를 표시합니다.

## GitHub Pages

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 검사, 테스트, 빌드 후 `dist`를 Pages에 배포합니다. 저장소 **Settings → Pages**에서 배포 원본을 **GitHub Actions**로 설정하세요. 사이트 주소는 `https://elecbrandy.github.io/random-pick/`입니다.
